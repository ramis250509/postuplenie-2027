# Поступление 2027 — дашборд

Рабочая версия: https://claude.ai/artifact/PxKxPESg1foZk58rwLdCrW. Её видите только вы. Данные синхронизируются между телефоном и компьютером.

## Файлы
- `app.html` — исходник дашборда (Preact + htm с CDN, сборщик не нужен). Именно он публикуется как артефакт.
- `index.html` — копия для открытия на компьютере без интернета-хранилища. Пересобирается командой `node build.mjs`. В этой копии данные лежат только в текущем браузере.

## Экраны
| Экран | Что на нём |
|---|---|
| Главная `#home` | ближайший дедлайн (по времени Бишкека), статусы заявок, срочные задачи, «сколько платить в год» в сравнении с бюджетом семьи |
| Вузы `#unis` | группы по странам со сводкой (подано, ближайший дедлайн, меньший остаток, full ride); сортировка по дедлайну, названию, остатку, статусу, категории; поиск и фильтры |
| Вуз `#uni-<id>` | статус, остаток к оплате, покрытие жилья и питания, дедлайны, требования, 3 слоя стоимости, стипендии, документы, файлы, следующие шаги, заметки |
| Задачи `#tasks` | просрочено, сегодня, эта неделя, позже, без срока |
| Настройки `#config` | курсы валют, бюджет семьи, резервная копия и импорт, ежедневная инструкция |

## Данные
- **Вуз**: название, город, страна, программа, статус, категория, валюта, ссылки, заметки.
  - `deadlines[]`: что за срок, тип, дата, время и часовой пояс вуза, источник, дата проверки, отметка о выполнении.
  - `costs`: три отдельных слоя.
    - `published` — опубликованная стоимость (COA) с источником.
    - `estimate` — ваша оценка.
    - `offer` — цифры из award letter.
  - `scholarships[]`: тип, статус, что покрывает (обучение, жильё, питание, страховка, перелёт), сумма в год, стипендия на жизнь, условия, источник.
  - `documents[]`: статус «нужно», «в работе», «готов» или «отправлен».
- **Задача**: текст, вуз, срок, приоритет.
- **Правило источников**: значение считается проверенным, только если у него есть ссылка и дата проверки. Иначе оно показывается как «Не проверено». Если проверка старше 45 дней, появляется жёлтая метка.
- **Мой остаток в год** считается так:
  - если внесено предложение вуза — по нему;
  - иначе берётся ваша оценка или опубликованная стоимость, и из неё вычитаются стипендии, отмеченные «учитывать».

## Импорт из PDF или текста
1. Нажмите «Из PDF или текста» (на странице вуза кнопка называется «Дополнить из PDF»).
2. Выберите, что дать Claude:
   - PDF или фото страницы;
   - вкладку «Текст» — туда можно вставить или написать текст своими словами.
3. Claude прочитает документ и предложит название, дедлайны, стоимость, стипендии, документы и требования. Вы снимаете лишнее и сохраняете.
4. Всё, что пришло из документа, помечено «Не проверено · из PDF, сверьте». Чтобы значение стало проверенным, сверьте его с официальной страницей и поставьте дату проверки.
5. Загруженный PDF остаётся в разделе вуза «Файлы». Если документ — скан без текста, Claude прочитает изображения первых страниц.

## Как загрузить свой список вузов
Есть три способа:
1. Через кнопку «+ Вуз».
2. Пришлите мне список: я внесу его прямо в хранилище.
3. Загрузите JSON-файл в «Настройки → Импортировать из файла». Формат такой же, как у резервной копии: `{ "unis": [...], "tasks": [...] }`.

## Ежедневное обновление (5–10 минут)
1. Откройте «Главную»: посмотрите ближайший дедлайн и блок «Срочно сделать».
2. Отметьте сделанное: галочки у задач и дедлайнов, статусы документов. Если пришло письмо от вуза, смените статус заявки.
3. Проверьте один факт с меткой «Не проверено» или жёлтой меткой на официальном сайте. Затем исправьте значение и нажмите «Сегодня» в поле даты проверки.
4. Всё новое, что узнали, сразу записывайте задачей со сроком.
5. Раз в неделю: обновите курсы валют, скачайте резервную копию, проверьте страницы стипендий. Даты на следующий год обычно публикуют с ноября по январь.
